配置

故事设定、人物卡、世界观条目与模型连接。写作风格要写成可执行规则，不要写「文笔好一点」。

故事类型每章字数 500–20000人物：外貌 / 动机 / 能力边界 / 说话方式一键立项

大纲

每批 1–36 章。第一次建议 3–6 章：拉榜单 → 选对标 → 抓免费章 → 拆解 → 按拆解排本批大纲。

七猫 / 晋江新书 / 热销 / 收藏 / 完结 / 更新日榜 / 月榜抓 3/6/10/20 章分批拆榜 → 分批排纲

写作

生成当前章 → 去 AI 味 → 审核 → 确认。确认后的章节才进入上下文，成为后续写作的依据。

正文 + 摘要 + 一致性检查章节修订 / 段落修订 / 人工编辑未确认不进下一章

校订

跨章检查：全局事实、设定是否被正文改掉、已确认章节之间有无矛盾。

冲突优先改正文改设定会污染后续章节

伏笔

规划 / 已埋 / 已回收三态台账。完结前必须过一遍未回收项，这是烂尾的主要来源。

埋在哪打算在哪收沉睡伏笔提醒

金句库

按题材建档，写作时化用。规则是禁止整句照搬，只借句式和节奏；实物题字除外。

公有领域每条带出处一章最多一处显性化用

记忆

人物、组织、世界观、关系与关键事实。正文改了但设定没跟上时，这里会显示「待同步」。

事实带出处冲突先拦下按相关性召回

图谱

实体关系图。群像戏、宅斗、多男主时，最容易写串的是称谓和立场。

人物关系势力归属出场追踪

技能

7 个已安装技能（5 个已注册启用）。技能用 skill.json 声明生效阶段，用 SKILL.md 写判定标准。
